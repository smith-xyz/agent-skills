# Weekly sync

Use for standup/sync updates. Two sections: Did and Doing. Each bullet leads with the Jira user story (when mapped) or "No user story", then the activity.

```markdown
Did
<STORY-KEY> <story summary>: <what was done>
<STORY-KEY> <story summary>: <what was done>
No user story: <untracked activity>
Doing
<STORY-KEY> <story summary>: <in progress>
No user story: <untracked in progress>
```
