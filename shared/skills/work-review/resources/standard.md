# Standard

~500 words. Summary + progress per item. Organize by work/theme; use Jira hierarchy only when "report by ticket" or project mapping was requested.

```markdown
# Work Review: Last <days> Days

## Summary

<2-3 sentence overview of progress against tracked work>

## Progress by Epic

### <PROJ-100> <Epic Summary>

**<PROJ-101> <Story Summary>** - <Status>

- <What was accomplished, drawn from transcript evidence>
- <Files or areas touched>

**<PROJ-102> <Story Summary>** - <Status>

- <What was accomplished>

### Standalone Tasks

- **<PROJ-200> <Task Summary>** - <Status>: <progress note>

## Untracked Work

<Activity found in transcripts with no corresponding Jira item. Keep brief.>
```
