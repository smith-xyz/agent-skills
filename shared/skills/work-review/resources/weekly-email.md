# Weekly email

Use for the weekly summary email. Numbered list; each item leads with the Jira user story (or "No user story"), then a sentence or two of progress.

```markdown
1. <STORY-KEY> <story summary> – <progress sentence(s)>.
2. <STORY-KEY> <story summary> – <progress sentence(s)>.
3. No user story – <untracked progress sentence(s)>.
```
